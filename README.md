# Банковские Игры - Demo Bank Games

Веб-приложение с 10 интерактивными играми на банковскую тематику.

## Описание

Это полностью работающее веб-приложение, состоящее из главной страницы и 10 различных игр. Все игры выполнены в едином стиле с красивым дизайном и полностью работают без бэкенда.

## Список игр

1. **Bubble Shooter** - "Салют из лишнего"
   - Классический bubble shooter с механикой стрельбы пузырьками
   - Бустеры и специальные эффекты
   - Прогрессивная система уровней

2. **Zuma** - "Череда сервисов"
   - Zuma-раннер с движущейся цепочкой шариков
   - Спиральный путь и динамичный геймплей
   - Комбо-система и бонусы

3. **Match-3** - "Финансовая уборка"
   - Классический match-3 с обменом элементов
   - Система целей и ограниченные ходы
   - Анимации падения и комбо

4. **Mahjong** - "Плитки минимализма"
   - Традиционный маджонг с многослойными плитками
   - Подсказки и перемешивание
   - Различные раскладки

5. **Onet** - "Чистая линия"
   - Соединение пар линиями с максимум двумя поворотами
   - Таймер и прогрессивная сложность
   - Умный алгоритм поиска пути

6. **Collapse Clicker** - "Цифровой детокс"
   - Кликайте на группы одинаковых элементов
   - Гравитация и цепные реакции
   - Увеличивающаяся сложность

7. **Hex Match** - "Мини-соты чистоты"
   - Игра на шестиугольном поле
   - Вращение групп сот
   - Уникальная механика совпадений

8. **Slide Puzzle Match** - "Собери чистый экран"
   - Комбинация пятнашек и match-3
   - Двигайте плитки и собирайте совпадения
   - Стратегический геймплей

9. **Mahjong Adventure** - "Чистый путь"
   - Путешествие по карте с маджонг-раскладами
   - 5 различных локаций
   - Прогрессивная история

10. **Match-3 Adventure** - "От хаоса к чистоте"
    - Match-3 с системой прогресса
    - Звездная система оценки
    - 5 уровней с увеличивающейся сложностью

## Как запустить

### Простой способ
Просто откройте файл `index.html` в браузере.

### Через локальный сервер (рекомендуется)
```bash
# Python 3
python -m http.server 8000

# Или Python 2
python -m SimpleHTTPServer 8000

# Затем откройте в браузере
# http://localhost:8000
```

### Через Node.js
```bash
# Установите http-server глобально
npm install -g http-server

# Запустите сервер
http-server

# Откройте в браузере указанный адрес
```

## Управление

### Общее для всех игр
- Кнопка "Назад" в левом верхнем углу для возврата в меню

### Для конкретных игр
- **Bubble Shooter, Zuma** - управление мышью, клик для выстрела
- **Match-3, Slide Puzzle** - клик по элементу, затем по соседнему для обмена
- **Mahjong, Onet** - клик по двум одинаковым элементам
- **Collapse** - клик по группе одинаковых элементов
- **Hex Match** - клик по соте для вращения группы
